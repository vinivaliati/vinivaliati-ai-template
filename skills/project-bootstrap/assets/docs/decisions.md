# Decision log

Newest first. One line per decision: date, what was decided, why. Decisions
that are hard to reverse and had real alternatives also get an ADR in
`docs/adr/`; link it here.

- <YYYY-MM-DD>: <Decision>. Why: <reason>.
- <YYYY-MM-DD>: <Decision>. Why: <reason>. ADR: [0001](adr/0001-<slug>.md)
